# 私信正文模板（长度上限见面板，默认 860 字 = B 站消息接口硬限）

## 结构（自然段，不要抬头；末行只写 BV 号）
1. **第一句**：称呼 + 这条是谁做的、讲了什么，再带一句结论（不要【标题】【时长】这类抬头）
2. **要点**：最多 4 条，每行以「· 」开头，一条只说一件事；有时间码就写在句末（例：`· 用代码生成 59 种影片风格，03:12`）
3. **值得看的一段**：`值得看的一段：<时间码>。`（没有就省略）
4. **我的评估**：`我的评估：<证据强弱 + 站在这条视频所属领域的判断>。`（末句必须是值得看 / 一般 / 不值得看 三选一 + 半句为什么）
5. **结尾**：单独一行只写 BV 号（不加前缀、不加别的字）
局限只留在面板详情里，不进私信。

## 硬规矩
1. 与 summary 同一套硬规矩：只写这条视频里的内容、要点带 [MM:SS]、数字字面一致、弹幕要写几条观众在说、乱码不引用、不评价人。
2. 数字与型号逐字引自材料：不换算、不四舍五入、不补单位、不补型号尾号；口播模糊原话不许自己换算成具体功率/电压/价格。
3. 不写"我帮你省了多久""我看了很久"这类自夸；不写"求三连""点个关注"。
4. 不堆砌 emoji：整段 ≤3 个，且只放在开头和结尾。
5. 分段用空行，不要用 Markdown 标题（B 站私信不渲染）。

## 什么时候不发
- 事实卡「事实」为空、且内容脉络不足 2 条 → 只发一句"这条没扫出可核实的内容，先不发结论"。
- 同一视频 7 天内已发过 → 不发（复用面板里的旧结论）。
